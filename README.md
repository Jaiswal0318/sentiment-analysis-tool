
# 💬 SentimentAI — Sentiment Analysis Tool

SentimentAI is a machine-learning web application that analyzes movie-review text and predicts whether its sentiment is positive or negative.

## Features

- Text sentiment classification
- TF-IDF text feature extraction
- Logistic Regression classifier
- Sentiment probability visualization
- Interactive Streamlit dashboard
- Model evaluation using a held-out test dataset

## Technologies Used

- Python
- Streamlit
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression

## Dataset

This project uses the NLTK Movie Reviews dataset, containing 2,000 labeled reviews:
- 1,000 positive reviews
- 1,000 negative reviews

The data is split into 80% training data and 20% test data, using a fixed random seed and stratification.

## Model Evaluation

The initial evaluation achieved **84.50% accuracy** on 400 held-out reviews.

This result applies to the specific dataset and split used in this project. Performance on other types of text may differ.

## Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/sentiment-analysis-tool.git
cd sentiment-analysis-tool
```

### 2. Create and activate a virtual environment

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Train the model

```bash
python train_model.py
```

The script downloads the NLTK Movie Reviews dataset if needed and saves the trained model under `models/sentiment_model.pkl`.

### 5. Launch the application

```bash
streamlit run app.py
```

## Limitations

- The classifier supports only positive and negative predictions.
- It was trained on movie reviews, so performance on product reviews, sarcasm, short comments, or other domains may vary.
- The displayed probability is a model estimate, not a guarantee that the prediction is correct.
